Refranero CLI · Architecture

How the binary is put together

One Rust executable, four layers of responsibility. The terminal prints, the core engine owns the local catalog and coordinates refresh work, the adapters talk to the network, and the remote portals are the only outside world. No plain read ever touches the network.

What the user gets

A read never touches the network

  • Every plain run answers from the SQLite catalog on disk.
  • HTTP only happens on an explicit sync, or on a background refresh when the cache is stale and --offline was not set.

Ownership

Adapters parse, the caller writes

  • ingest.rs turns remote HTML into catalog rows and returns them.
  • update.rs orchestrates source work and the persistent Wayback cursor; main.rs runs worker callbacks.
  • refresh.rs defines cadence, the five-minute lease, and the incremental Wayback cap. store.rs owns persistence.
