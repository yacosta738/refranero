Refranero CLI · Reading flow

What happens when you run it

Interactive startup checks refresh policy and the five-minute lease, and may spawn a detached worker before it reads and displays the first entry. One-shot random prints its local entry before scheduling eligible due work. The lease usually prevents overlap, but a worker delayed beyond expiry may overlap a replacement worker.

Fast path — what you always get

  • The terminal prints a result in one SQLite read, with no network round-trip.
  • Example row returned: "Más vale pájaro en mano que ciento volando" (category refran).

Background path — kept out of your way

  • Interactive startup checks policy and the lease, and may spawn its worker before the first local read. One-shot random prints first, then may schedule eligible due work.
  • The five-minute lease usually prevents overlap. A worker delayed beyond expiry may overlap a replacement worker.
  • If another process already holds the lease, this run skips the refresh entirely.
  • --offline disables this path entirely for that invocation.
  • One-shot can refresh due Cervantes Virtual work, but cannot start full Wayback bootstrap. A resumed bootstrap processes all remaining letters through Z; only after it completes does a later update process one letter per run.
  • In the reader, u requests a forced online update if a lease is available; s toggles catalog statistics.
