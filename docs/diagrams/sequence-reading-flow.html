Refranero CLI · Reading flow

What happens when you run it

Interactive startup may schedule refresh before reading and displaying the first local entry; one-shot random output prints first, then may schedule refresh. A five-minute lease usually prevents overlapping workers, but a worker delayed beyond lease expiry may overlap a new worker. The reader does not wait for refresh.

Fast path — what you always get

  • The terminal prints a result in one SQLite read, with no network round-trip.
  • Example row returned: "Más vale pájaro en mano que ciento volando" (category refran).

Background path — kept out of your way

  • Interactive startup may start bootstrap A–Z or resume multiple remaining letters through Z. Only updates after bootstrap completion process one letter.
  • The five-minute lease usually prevents overlapping workers. A worker delayed beyond lease expiry may overlap with a newly started worker.
  • If another process already holds the lease, this run skips the refresh entirely.
  • --offline disables this path entirely for that invocation.
  • One-shot random output prints first, then may schedule a due Cervantes Virtual refresh; it does not start Wayback bootstrap. In the reader, u requests an update and s toggles catalog statistics.
