Refranero CLI · Reading flow

What happens when you run it

Interactive startup reads from the local catalog first, then may schedule background refresh work. A five-minute lease prevents overlapping workers; the reader does not wait for refresh.

Fast path — what you always get

  • The terminal prints a result in one SQLite read, with no network round-trip.
  • Example row returned: "Más vale pájaro en mano que ciento volando" (category refran).

Background path — kept out of your way

  • Interactive startup may schedule a Wayback bootstrap, which processes letters A–Z. Later update runs process one letter.
  • It takes a time-boxed lease, so two overlapping runs cannot race each other.
  • If another process already holds the lease, this run skips the refresh entirely.
  • --offline disables this path entirely for that invocation.
  • One-shot random output does not start Wayback bootstrap. In the reader, u requests an update and s toggles catalog statistics.
