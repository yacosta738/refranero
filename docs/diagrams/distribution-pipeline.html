Refranero CLI · Distribution

From source to three install paths

One Rust source tree, one release workflow, three ways to install the same binary: cargo install, npm install, or docker run. The npm package never downloads a binary at install time — it only dispatches to a platform package chosen ahead of time.

One trigger, three publish jobs

  • A tagged release builds Linux and macOS binaries on 4 native runners (x64/arm64).
  • Windows x64/arm64 builds natively inside the npm publish job, not ahead of time.
  • Only the npm packages use prebuilt binaries; crates.io and Docker build from source.
  • A recovery workflow_dispatch with a release tag skips registry publishing.

npm is a thin dispatcher

  • npm/wrapper ships a small launcher script, no binary inside it.
  • It resolves and runs the one optional native package matching the user's OS/CPU.
  • scripts/prepare-npm.mjs holds the platform map used to build the packages.

Supported platforms

  • macOS, Linux (glibc), Windows — each on x64 and arm64.
  • Linux musl is intentionally not a configured target.
